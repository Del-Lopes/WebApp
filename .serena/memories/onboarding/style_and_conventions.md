# Style and Conventions

## Preferences
* **Tailwind CSS**: Core utility-first CSS framework.
* **TypeScript**: Enforce types across the project.
* **Component-based architecture**: Reusable logic and views in `components/`.
* **State Management**: Using React Context API for global state.
* **Head Management**: Page titles and meta tags managed using `react-helmet-async` in `App.tsx`.
* **Icons**: Using `lucide-react` library.

## File Naming
* Component files: PascalCase (`Sidebar.tsx`, `Logo.tsx`).
* Hooks/Lib: camelCase or descriptive names.
* Constants/Types: `constants.ts`, `types.ts`.
