# Suggested Commands

## Development
* `npm run dev`: Start Vite development server.
* `npm run build`: Build for production.
* `npm run preview`: Locally preview production build.

## Utilities (Windows/PowerShell)
* `git status`: Check local changes.
* `git add .`: Stage all changes.
* `git commit -m "Your message"`: Create a new commit.
* `git push`: Push changes to the remote repository.
* `dir`, `ls`: List files in a directory.
* `type <file_name>`, `cat <file_name>`: Read file content.

## Completion Protocol
After any change:
1. Verify build: `npm run build`.
2. Push to GitHub: `git add .`, `git commit`, `git push`.
