# Project Overview: Trader AFK (formerly AFK Trade)

Web-based algorithmic trading learning and management platform for traders.

## Tech Stack
* **Vite**: Build tool and dev server.
* **React 19**: Frontend UI library.
* **TypeScript**: Static typing.
* **Supabase**: Backend-as-a-Service for database, auth, and more.
* **Lucide-React**: Icon set.
* **Tailwind CSS**: Utility-first CSS (implied by classes like `text-3xl`, `font-bold` in search results).
* **React Helmet Async**: Head management for SEO/meta.

## Codebase Structure
* `/components`: UI components organized by module.
* `/contexts`: React contexts for state management.
* `/lib`: Libraries and utility functions (e.g., Supabase client).
* `/public`: Static assets (images, manifest, robots.txt).
* `/docs`: Project documentation and plans.
* `App.tsx`: Main application entry point with routing and page titles.
* `constants.ts`: Static data and configurations.
